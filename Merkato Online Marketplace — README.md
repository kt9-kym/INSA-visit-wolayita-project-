# 🛒 Merkato Online

**Merkato Online** is a web-based marketplace that connects buyers and sellers in one digital platform. Users can browse products, search for items, view product details, and place orders online.

## 🎯 Project Goal

The goal of Merkato Online is to make buying and selling easier, faster, and more accessible. It can help local businesses and individual sellers display their products online and reach more customers.

## ✨ Features

- 👤 User registration and login
- 🔎 Product search
- 📦 Product categories
- 🖼️ Product images and details
- 💰 Product prices
- 🛒 Shopping cart
- 📋 Order placement
- 🚚 Order status tracking
- 🏪 Seller product management
- 💬 Customer–seller communication
- 💳 Payment integration
- 🛠️ Admin dashboard
- 📱 Responsive design for mobile and desktop

## 👥 User Roles

### 🛍️ Customer
- Create an account
- Browse products
- Search for products
- View product details
- Add products to cart
- Place orders
- Track orders

### 🏪 Seller
- Create a seller account
- Add products
- Update product information
- Manage stock
- Receive and manage orders

### 👨‍💻 Administrator
- Manage users
- Manage sellers
- Manage products
- Manage categories
- Manage orders
- Monitor the marketplace

## 🔄 How It Works

```text
Customer
   ↓
Register / Login
   ↓
Browse Products
   ↓
Search & Select Product
   ↓
Add to Cart
   ↓
Place Order
   ↓
Seller Receives Order
   ↓
Seller Processes Order
   ↓
Customer Receives Status Update
```
